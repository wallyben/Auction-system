# Safe-start programme

`SAFE_START_MODE=true` by default.

Until LEVEL 4 evidence exists:

- max purchase €250 (`SAFE_START_MAX_PURCHASE_EUR`)
- minimum valuation confidence 0.85
- downside profit ≥ 0
- one position per category via `MAX_CATEGORY_EXPOSURE`
- alerts only on `BUY_READY`

First real purchases, when any `BUY_READY` appears: €100–€250, exact identity, realised comps present, high liquidity, no counterfeit flag.

Do not disable SAFE_START to manufacture a green status.
